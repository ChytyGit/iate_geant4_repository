Здесь хранится актуальный код проекта, а также дополнительные материалы для обучения.

---

##  Что находится в репозитории?

*   **`project/`** — **Актуальная версия проекта.**
    Здесь находится весь исходный код (C++), готовый к открытию и сборке в Visual Studio.
*   **`additions/`** — **Дополнительные материалы.**
    *   `presentations/` — презентации с прошедших занятий.
    *   `helpful sources/` — полезные книги, справочники и ссылки для разработчика.
*   **`.gitignore`** — служебный файл Git.

---

##  Способ 1. Как легко скачать ТОЛЬКО папку `project` (через сайт)

Самый простой способ, не требующий установки дополнительных программ. Так как в папке `additions` лежат тяжелые файлы, скачивать весь репозиторий целиком не всегда удобно.

1.  Находясь на главной странице этого репозитория, нажмите зеленую кнопку **`Code`**.
2.  В выпадающем меню выберите **`Download ZIP`**.
3.  На ваш компьютер скачается ZIP-архив со всем содержимым репозитория.
4.  Распакуйте этот архив.
5.  В распакованной папке найдите папку **`project`**. Скопируйте её в удобное для вас место.
6.  Остальные папки (`additions`) можно просто удалить.

## Способ 2. Копирование через терминал (Git)

Если у вас установлен **Git**, вы можете склонировать проект прямо из командной строки. Это удобнее, если вы планируете обновлять код по мере выхода новых занятий.

Этот метод позволяет не качать тяжелые презентации и книги, а получить только исходный код.

Откройте терминал (Git Bash, PowerShell или CMD) и выполните:

```bash
# 1. Клонируем репозиторий, но пока не скачиваем файлы
git clone --no-checkout <URL_вашего_репозитория>
cd <имя_репозитория>

# 2. Включаем режим выборочного скачивания
git sparse-checkout init --cone

# 3. Указываем, что нам нужна только папка project
git sparse-checkout set project

# 4. Скачиваем файлы
git checkout main
